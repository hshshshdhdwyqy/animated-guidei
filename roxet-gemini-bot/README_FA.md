# 🤖 RoXeT AI — ربات تلگرام هوش مصنوعی Gemini

ربات کامل با پنل مدیریت داخل خود تلگرام، نصب یک‌خطی روی سرور (مثل میرزابات) و دکمه‌های شیشه‌ای (Inline).

|---|---|

| 🖼 تحلیل عکس | عکس بفرست، توضیح می‌دهد، متن داخل عکس را می‌خواند و ترجمه می‌کند |

## 1️⃣ آماده‌سازی (فقط ۳ چیز)

1. **توکن ربات:** در تلگرام به [@BotFather](https://t.me/BotFather) برو، `/newbot` بزن و توکن را بردار.
2. **آیدی ادمین (عددی):** لازم نیست دستی پیدا کنی؛ نصب‌کننده خودش از پیامی که به ربات می‌دهی تشخیصش می‌دهد. (یا از [@userinfobot](https://t.me/userinfobot))
3. **کلید Gemini API:** از <https://aistudio.google.com/apikey> بساز. این را **بعد از نصب داخل خود ربات** می‌دهی.

> ⚠️ **اشتراک Gemini Pro (Google AI Pro) خودش کلید API نیست.** کلید API از Google AI Studio ساخته می‌شود و سهمیه‌ی جدا دارد؛
> سطح رایگان دارد و برای مدل‌های پرقدرت‌تر/تصویر ممکن است لازم باشد Billing فعال کنی.
>
> 🔒 کلید قبلی‌ای که قبلاً در چت منتشر شد را در AI Studio **حذف/باطل** کن و یک کلید تازه بساز.

## 2️⃣ گذاشتن پروژه روی گیت‌هاب (یک‌بار)

1. در GitHub یک Repository **Public** بساز، مثلاً `roxet-gemini-bot`.
2. همه‌ی فایل‌های همین پوشه را در آن آپلود کن (Add file → Upload files).
   `.env` یا هر کلیدی را آپلود نکن؛ `.gitignore` هم جلویش را می‌گیرد.
3. فایل `install.sh` را در GitHub باز کن، دکمه‌ی ✏️ را بزن و این خط بالای فایل را با آدرس ریپوی خودت عوض کن:
   ```bash
   DEFAULT_REPO="https://github.com/YOUR_GITHUB_USER/roxet-gemini-bot.git"
   ```
   و Commit بزن.

## 3️⃣ نصب روی سرور (یک دستور)

سرور باید **Ubuntu 22.04+** یا Debian، با دسترسی root و **خارج از ایران** باشد (Gemini از ایران قابل‌دسترس نیست). با SSH وصل شو و بزن:

```bash
bash <(curl -Ls https://raw.githubusercontent.com/YOUR_GITHUB_USER/roxet-gemini-bot/main/install.sh)
```

(`YOUR_GITHUB_USER` را با نام کاربری گیت‌هاب خودت عوض کن.)

نصب‌کننده فقط این‌ها را می‌پرسد:

1. **Bot token** — توکن BotFather
2. **Admin numeric ID** — اگر `Enter` بزنی، می‌گوید به ربات پیام بده و آیدی را خودش پیدا می‌کند

بقیه‌ی کارها (نصب پایتون، محیط مجازی، سرویس systemd برای اجرای همیشگی و ری‌استارت خودکار) خودکار انجام می‌شود.

> بدون گیت‌هاب هم می‌شود: zip را روی سرور باز کن و داخل پوشه `sudo bash install.sh` بزن.

## 4️⃣ اولین بار در تلگرام

1. ربات را باز کن و **Start** بزن (منوی شیشه‌ای می‌آید).
2. **🛠 پنل مدیریت ← 🔑 کلید API ← ✏️ ثبت / تغییر کلید** و کلید Gemini را بفرست.
   ربات پیام تو را فوراً پاک می‌کند، کلید را تست می‌کند و اگر مدل پیش‌فرض برای کلیدت موجود نباشد، خودش مدل مناسب را انتخاب می‌کند.
3. «🧪 تست اتصال» و در «🧠 مدل‌ها» «🧪 تست ساخت تصویر» را بزن.

تمام! همه‌ی کاربران بدون پلن پولی، VIP، خرید اعتبار یا درگاه پرداخت از امکانات رایگان ربات استفاده می‌کنند. فقط هزینه/سهمیه‌ی مصرف API گوگل تابع محدودیت‌های حساب API مدیر است.

## 🔎 فعال‌سازی حالت Inline

در BotFather دستور `/setinline` را اجرا کن، ربات را انتخاب کن و یک متن راهنما (مثلاً «سؤالت را بنویس») تنظیم کن. سپس در هر گفتگوی تلگرام بنویس `@username_bot سؤال شما` و نتیجه را انتخاب کن.

## 👥 استفاده در گروه

ربات را به گروه اضافه کن (ادمین‌کردنش لازم نیست). در گروه:

- `/ask سؤال شما`
- منشن کردن: `@یوزرنیم_ربات سؤال شما`
- ریپلای روی پیام‌های خود ربات برای ادامه‌ی گفتگو
- ریپلای روی هر پیام یا فایل + `/explain` یا `/summarize` یا `/translate`
- `/img توضیح تصویر`

ادمین از «💬 گروه‌ها» در پنل می‌تواند هر گروه را فعال/غیرفعال کند یا ربات را از آن خارج کند، و از «⚙️ تنظیمات» کار در گروه‌ها را کلاً خاموش کند. هنگام اضافه‌شدن به گروه جدید، به ادمین خبر می‌رسد.

## 🧰 مدیریت سرور

بعد از نصب، در هر زمان روی سرور بنویس:

```bash
roxet
```

منو: به‌روزرسانی از گیت‌هاب، ری‌استارت، لاگ زنده، تغییر توکن/ادمین، بکاپ، توقف، حذف.
برای آپدیت: تغییراتت را در GitHub بگذار و از منو «Update» را بزن (کاربران و تنظیمات حفظ می‌شود).

## ⚠️ نکته‌ها

- **خطای سهمیه (۴۲۹):** سطح رایگان Google محدودیت دارد؛ سقف روزانه‌ی کاربران را از «⚙️ تنظیمات» پایین بیاور یا Billing فعال کن.
- **اسم مدل‌ها زود عوض می‌شود:** در «🧠 مدل‌ها» لیست واقعی مدل‌های کلیدت را می‌بینی و با یک ضربه انتخاب می‌کنی.
  مدل تصویر پیش‌فرض `gemini-2.5-flash-image` است؛ `gemini-3-pro-image-preview` و `imagen-4.0-*` هم قابل انتخاب‌اند
  (Imagen فقط «ساخت» دارد، «ویرایش» با مدل‌های gemini-…-image انجام می‌شود).
- **حجم فایل:** حداکثر ۱۵ مگابایت (محدودیت تلگرام برای ربات‌ها ۲۰ مگابایت).
- **هزینه:** این پروژه پرداخت و اشتراک کاربری ندارد؛ اما استفاده از Gemini API ممکن است طبق تعرفه و سهمیه‌ی Google برای صاحب کلید هزینه‌دار یا محدود باشد. مدل‌های TTS/ویدیو نیز باید در دسترس کلید باشند؛ در صورت خطای دسترسی، نام مدل را در `.env` یا تنظیمات سرور اصلاح کن.
- **عضویت اجباری:** ربات باید ادمین کانال باشد.
- سقف روزانه مخصوص کاربران عادی است؛ ادمین‌ها نامحدودند. چند ادمین: در `.env` بنویس `ADMIN_IDS=111,222`.
